# Entra ID 3LO with AgentCore Gateway

This sample demonstrates an Agent connecting to AgentCore Gateway with built-in 3LO support for Microsoft Graph.

## Architecture

```
User ──[ID Token]──► Agent ──► Gateway ──[3LO]──► Microsoft Graph
```

## Quick Start

```bash
pip install -r requirements.txt
jupyter notebook Step_by_Step_Entra_ID_3LO_Gateway.ipynb
```
